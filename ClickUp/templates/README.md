# Templates de cartões e evidências

Os templates canônicos continuam em `../../plan/templates/` e devem ser usados
para preencher artefatos anexados aos cartões. O índice abaixo define o uso:

| Artefato | Template |
|---|---|
| ADR | `../../plan/templates/adr.md` |
| Story | `../../plan/templates/user-story.md` |
| Task | `../../plan/templates/task.md` |
| Strategy Spec | `../../plan/templates/strategy-spec.md` |
| Risk Policy | `../../plan/templates/risk-policy.md` |
| Promotion Readiness | `../../plan/templates/promotion-readiness-matrix.md` |
| Canary | `../../plan/templates/canary-plan.md` |
| Release Evidence | `../../plan/templates/release-evidence.md` |
| Reconciliation | `../../plan/templates/reconciliation-report.md` |
| Runbook | `../../plan/templates/runbook.md` |
| Experiment/Dataset/Model Card | arquivos correspondentes em `../../plan/templates/` |

Não duplique templates sem atualizar a fonte canônica. O cartão deve apontar
para o template e registrar a instância versionada como evidência.
