# Documentation checklist

- [ ] Runtime and framework versions identified.
- [ ] Package versions read from manifests or lockfiles.
- [ ] Official source selected for each non-trivial API.
- [ ] Context7 retrieval constrained to the relevant library and version.
- [ ] No undocumented API, option, or dependency invented.
- [ ] Error, security, compatibility, and deprecation behavior checked.
- [ ] Build, tests, type checking, lint, and formatting executed as applicable.
- [ ] Sources and version assumptions recorded in the result or decision record.
