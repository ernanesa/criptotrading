# .NET Router

Inspect the target framework, SDK, language version, package manifests, and task type before selecting guidance.

- API or web pipeline: use software-development plus versioned-docs-workflow.
- EF Core, queries, migrations, or persistence: add code-review and architecture-review as needed.
- Async, channels, locks, or throughput: add financial-observability for trading paths and diagnose for regressions.
- Upgrade or compatibility work: use versioned-docs-workflow and produce a migration note.
- Test-first feature or bug fix: add tdd-development.
- Financial order, balance, or execution code: add financial-observability and trading-strategy-engineering.

Do not load every skill by default. Route narrowly and escalate to broader review only when the change crosses boundaries.
