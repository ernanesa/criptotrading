# Delivery checklist

## Scope

- [ ] Requirement and acceptance criteria are understood.
- [ ] Non-goals and assumptions are explicit.
- [ ] No unrelated files or behavior were changed.

## Backend

- [ ] Validation and authorization are covered.
- [ ] Success, failure, timeout, cancellation, and not-found behavior are defined.
- [ ] Persistence changes have a migration and rollback consideration.
- [ ] Logs and errors avoid secrets and useful diagnostics are available.

## Frontend

- [ ] Loading, empty, error, success, and retry states are handled.
- [ ] Boundary data is typed and validated.
- [ ] Keyboard, screen reader, focus, and responsive behavior are considered.

## Verification

- [ ] Unit tests pass.
- [ ] Integration or contract tests pass where relevant.
- [ ] Build, type check, lint, and format checks pass.
- [ ] Documentation and API contracts are updated.
- [ ] Diff and residual risks were reviewed.
